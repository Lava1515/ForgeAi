### Static Fixes Applied

1. **`maps.py` - Camera `view()` span clamping**:
   - `span` parameter allows forcing visible width in world units (e.g. for close zooms).
   - Previously, `d = max(need_w / 2 / hh, need_h / 2 * math.sin(el) / hv, min_span / 2 / hh)` unconditionally applied `min_span` (default 1.5), overriding any forced `span < 1.5`.
   - Fixed to apply `min_span` only when `span is None`. Explicit spans must be finite and positive; invalid spans raise `ValueError` instead of producing a zero-distance camera.

2. **`maps.py` - `facts()` ratio division guard**:
   - Added `cb.area_km2 > 0` guard to prevent `ZeroDivisionError` when comparing countries where data outline area is missing or zero.

3. **`maps.py` - `_round2()` precision for small territories**:
   - Previously, `int(round(v / e) * e)` truncated numbers `< 10` to integers, turning small territories like Vatican (0.9 km²) to `0` and Tuvalu (7.3 km²) to `7` (losing second significant digit).
   - Fixed so that values `< 10` retain two significant figures (`round(val, 2)`), while values `≥ 10` remain clean integers.

4. **`world_map.py` - `build()` highlight parameter flexibility**:
   - Enhanced `world_map.build(..., highlight=...)` to accept either an ISO string / country name or a `dict` of keyword arguments (e.g., `{"key": "BRA", "color": (1.0, 0.55, 0.1), "lift": 0.25}`) passed directly to `wm.highlight(**highlight)`.
